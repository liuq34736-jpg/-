## 必须继续保留的边界

- **可靠传统依据**：五类关系、主体旺衰原则、互中变终、看爻辞及不拘体用。
- **现代解释**：把古籍“吉凶”限定为结构倾向、把“耗失”解释为一般向外耗用而非必然破财。
- **项目约定**：固定体用版本、精确节气换月、00:00 换日、三态“平”、四角色标签、上下辅助分别比较、去重复、混合冲突不评分。
- **争议**：乾坤互卦例外与 v1 统一计算；章节/起卦方式之间的优先级细节。本轮不改变冻结结果。
- **待研究**：动爻语义的条件极性编码与冲突裁决、专业问事规则、外应与克应、应期。不能宣传这些能力已实现。
