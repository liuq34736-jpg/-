## 证据故障

| 故障 | 后端处理 | 前端处理 |
| --- | --- | --- |
| 条件目录/依赖指纹变化 | 不信任新目录；evidence_unavailable | 保留可靠卦象，排除扩展判断 |
| 动爻 Frame 不存在、绑定/签名不能通过 | 原固定检查排除该资格 | 不显示被排除的动爻裁决 |
| 引用变化、条件原文未绑定 | 原目录 lookup 拒绝 | 无未经审查提醒或最终倾向 |
| 规则扫描页不完整/损坏 | 原 Rulebook 检查；相关判断不可用 | 只保留可靠结构 |
| 冻结生产文件基线变化 | 固定子进程拒绝计算，503 | 普通中文错误，清除旧结果，不伪造新结果 |
| 未知字段、内部字段或资格状态矛盾 | 服务白名单拒绝；浏览器再次校验 | 扩展回退，只有独立有效 reading 可保留 |
| 网络/服务超时 | 无无限重试，无真实 AI 补写 | 中文错误；不展示原始异常或 JSON |

损坏测试均采用内存或浏览器传输替身，未修改生产文件。网站没有公开故障注入入口。384 个路由在内存 ASGI 中执行真实校验和判断，固定子进程输入由新取得的签名批次结果复用；Chrome 代表案例另走真实本地 HTTP 服务。
