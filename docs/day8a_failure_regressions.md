## 意图与事实处理

Q04/Q07/Q22 对“下周/今年”等明确未来窗口的遗漏：新契约禁止同时标记 `missing=time_window`。过去“认识一个月”不是未来预测窗口。

原问题片段精确绑定起止位置；疑问、目标、指令不得标为既定事实。转述必须保留 reported_speech。这些检查未证明真实模型可以完整正确提取所有事实；本轮没有调用真实意图模型。

## 正例的准确含义

固定贲初九，business/relationship 两个手写测试替身应用产生不同文本；计算与四个批准 Frame 完全一致。结果标 `OFFLINE_ACCEPTED`、`production_approved=false`。它检验契约、证据绑定和渲染边界，**不证明真实 AI 已实现可靠个性化解释**。

## 仍需验收的质量风险

1. 已知语句/词表不能覆盖开放自然语言；未见词汇仍可能编造事实。
2. 六项全 true 曾发生误批准；必须独立读原文抽查，不能只看 receipt。
3. Q14 固定 hold 是保守局部处置，不是全库缺失条件的自动修复。
4. 同厂商独立请求仍可能相关错误；跨模型复核方案尚未验证。
5. 保守 gate 会有误拒绝，例如含“对方已经”的否定提醒；不降低门槛换批准率。
6. 旧失败缓存成本问题：提出短期负缓存方案，未实现、未触碰旧缓存。

本轮无真实模型批准率、无新真实 token/latency，不能宣布旧 FAIL 已经过实时质量验收。
