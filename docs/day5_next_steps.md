# Day 5：验收后建议与网页方案

**本轮到此停止。以下均为建议，未实施、未验证，不能视为已交付功能。**

## 规则验收顺序

1. 先检查五关系表、原扫描页及来源矩阵，确认本轮有限倾向的表达范围。
2. 审核旺衰定性修饰、互变辅助比较、重复处理和保留冲突的项目约定。
3. 重点人工式检查观六四与随六二：理解“体用结构倾向”与“动爻条件”两者分开保存，不能把该原型标签当全卦最终结论。
4. 单独研究并验收动爻条件极性结构、与体用相反时的裁决规则。不得靠关键词、临时 AI 判断或改写原 Frame 凑完整总论。
5. 对乾坤无互继续保留现有冲突。若将来更改计算，必须另开版本；不改 v1 与历史。
6. 用户验收独立原型后，再另开网页接入阶段。不能借此次 Day 5 自动进入个性化 AI 问事解释。

## 网页优化方案

本轮没有修改 CSS、React、导航或 API。

只读检查显示：当前梅花页 `max-width: 980px`，通用 `.page-panel` 为 900px；结果正文 14px，部分来源/爻位标签为 10px。因此建议针对梅花结果主区和小字样式调整，保留外层工作区布局。以下尺寸只是方案，不是已经改动后的实测值。

| 范围 | 建议 | 后续验收 |
| --- | --- | --- |
| 桌面主区 | 结果区可用宽度建议约 1100–1200px，实际阅读段落仍限制行长；不要无限铺满 | 1366/1440/1920 宽度、不同缩放与无横向溢出 |
| 移动正文 | 主正文建议 16–18px，行高 1.65–1.8；辅助标签不低于约 13–14px | 320/390/430 宽度、200% 字体放大与点击目标 |
| 结果页总论 | 在卦象概览后预留“综合断卦”卡，先给基础关系、关键爻义条件、限制和相反因素 | 原型未获正式验收时不展示最终裁决或伪称完成 |
| 详细卦义 | 本卦/动爻/互/变继续可展开，不默认堆满原文 | 普通阅读清楚，展开可查原批准内容 |
| 古籍依据 | 默认折叠，显示书名、版本、卷页、规则 ID 和核验方法；字形异文中立显示 | 不将现代解释冒充传统原文，不泄露内部签名或缓存 |
| 不确定性 | 保留“相反条件并存”“该层尚未裁决”的轻量说明 | 不显示成功概率、吉凶分数或确定成败 |
| AI 正文 | 未完成最终验收与独立审核的 AI 内容不进入正式结果 | AI 不能覆盖卦象、体用、旺衰或决定本引擎方向 |

## 接入前的明确依赖

- 动爻条件裁决与综合优先级需要独立规则审查；本原型还没有完整圆机综合能力。
- 原型本地源图像审查状态不是生产 `machine_verified` 自动迁移；正式接入需验收独立规则书与指纹策略。
- 必须设计新结果的版本快照与回放边界，不能修改原 42 条历史或用新规则重算旧记录。本轮没有修改 SQLite 或保存判断历史。
- 问题专属现实应用和行业占法仍未完成，不用临时 AI 补位。
- 既有依赖安全告警及真实跨设备验证仍需按原阶段计划处理；本轮未新增依赖或公开部署。

## 本轮可验收与不可验收

可验收：独立离线运行、来源追溯、五关系/旺衰/辅助因素、冲突保留、签名 Frame 原文保留、失败排除和算法保护。

不可宣称：正式网页综合断卦上线、已完成全爻义条件裁决、已完成个性化问事 AI 质量验收、可预测具体收益/健康/应期。
