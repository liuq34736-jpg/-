# Day 5：传统综合判断规则书

版本：`traditional_judgement_v1`；状态：**独立离线原型，等待验收**。日期：2026-10-09。

## 能力边界

本轮实现体用倾向、旺衰修饰、互变辅助因素、冲突保留、动爻与四角色已批准语义的完整引用。**当前不是已完成全部爻义条件裁决的传统综合断卦系统**。

输出的 `combined_tendency` 只覆盖 **体用、时令、辅助生克层**，明确附带 `semantic_polarity_included=false`、`is_final_outcome=false`。动爻提示单列，其条件没有被偷偷转换为吉凶票数。没有数值评分、概率、应期、现实成败承诺或问事类型专属预测。

先前 Day 1/3/4 材料把 `traditional_judgement_v1` 标记为未实现；未发现可复用的完整规则表/引擎。复用了现有来源审计、固定计算、签名 Frame 与读取隔离设施。原生产来源分类文件保持原状。

## 规则来源等级

| 标记 | 含义 | 运行策略 |
| --- | --- | --- |
| DIRECT_SOURCE | 指定古籍扫描原页直接支持所述关系或原则 | 只执行对应有限规则 |
| MODERN_INTERPRETATION | 将传统判断限定表达为现代结构倾向 | 不冒充古籍原文 |
| PROJECT_CONVENTION | 项目选定的标签、细化和保守冲突策略 | 必须保留版本和说明 |

| NOT_YET_SOURCED | 未得到可执行的可靠来源支持 | REFERENCE_ONLY，不生成该类判断 |

## 旺衰修饰

直接原则：卷二《衰旺論》PDF p.90（原页三六），体宜旺、生体一方宜旺、克体一方宜衰；体衰而得生，原书称“衰稍解”。

输入完全沿用 `meihua_strength_v1` 的 `wang / shuai / neutral`，不重新计算，不加入“相、休、囚、死”。`neutral` 是本项目未被指定为旺/衰的“平”，不可当作原书五级休囚状态。

| 条件 | 记录的修饰 | 方向处理 |
| --- | --- | --- |
| 体旺 | 主体时令条件较有利 | 不保证现实结果 |
| 体衰 | 主体时令条件受限 | 不等于必败 |
| 用克体，用衰 | `controlling_side_weak` | 保留不利基础关系，同时记录限制条件 |
| 用克体，体衰 | `weak_body_under_control` | 加强谨慎，不输出灾祸 |
| 用生体，用旺 | `supporting_side_wang` | 生助时令条件较有利 |
| 用生体，用衰 | `supporting_side_weak` | 生助受限，不取消生助 |
| 用生体，体衰 | `weak_body_receives_support` | 记录“稍解”的条件，不声称已经恢复 |
| 体克用，体衰 | `weak_subject_control_limited` | 项目细化：主体制约能力受限，不翻转关系 |
| 体生用，体衰 | `weak_subject_outflow` | 项目细化：保留耗用提醒，不推定实际损失 |

`TJ-STRENGTH` 为直接原则，`TJ-QUALIFIER` 为程序定性标签约定。没有旺衰补偿公式。不会出现“木衰，因此不克土”的推断。

## 各部分作用与优先级

原书《占卜總訣》p.55–56 有先看爻辞、再看体用的说明；《體用總訣》p.59–60 有体主、用事、互中、变终；《卦斷遺論》p.58 又提醒“不必拘体用”。这些不证明有一套适用于所有起卦方式、没有争议的程序排序。

本原型采用以下 **项目约定**：

1. 本卦已批准语义：当前背景。动爻已批准语义：关键变化提示。完整保留 `core_claims / conditions / cautions` 和证据绑定。
2. 本卦体用关系：基础传统倾向；旺衰：关系的条件修饰。都不能覆盖动爻的限制条件。
3. 互卦：内部过程的低优先级旁证。变卦：变化方向的低优先级旁证，不当作必然未来。
4. 互、变两个三爻卦对 **原体五行** 比较；关系仍调用冻结五行函数，没有重新分配体用。这一具体比较方式是 `TJ-AUXILIARY` 项目细化。
5. 同一个互卦的重复三爻结构只记录一次关系；变卦中未动的原体部分只作背景，不新增有利“票数”。所有因素都不计票、不相加。

`TJ-TRADITIONAL-ROLES` 记录原书原则；`TJ-ROLE-CONTEXT / TJ-PRIORITY` 记录项目映射和优先级。不能把 `current_state` 等程序标签称为古籍原文。

## 冲突与无法判断

- 有利、不利因素并存：保存双方 ID，输出 `mixed / unresolved_no_scoring`。同时保留本卦基础倾向，没有多数决、抵消或成功分数。
- **爻义可能另有条件或警示**：当前 Frame 尚无已审核的“条件极性裁决表”。不按“吉”“不利”“宜”等关键词猜测极性，也不把动爻默认为支持体用。始终注明该未完成环节。
- 无可靠体用规则来源：`insufficient_rule_support / undetermined`。辅助关系不能替其生成总判断。
- 缺少或损坏 Frame/原证据/原签名：排除该角色具体语义，保留其他可靠角色及确定性结构，并记录原因。
- 乾坤无互：原书 p.15 与统一取互的 `meihua_analysis_v1` 有既存冲突。**不改计算**；原型保留原始互卦，只将乾坤互卦关系标记 `reference_only`，不参与方向合成。冲突仍未解决。
- 未提供现实事实、专业问事分类、外应、克应、应期及金额：不补写、不判断。

因此“随六二体用层偏有利”不能被展示成“随六二全卦有利”：其已批准动爻提示仍是“顾着小的，就顾不上大的”。该提示与体用层一起保留，尚未执行条件极性裁决。

## 发布前限制

输入工厂只接收 Day 4 白名单请求，固定只读子进程签发不可变输入。引擎不接受调用者提交的任意计算 JSON；规则数据和扫描页 SHA-256 固定。仅允许限制来源，不允许加载自定义规则、路径、模型或 prompt。

本轮无网页路由、无历史写入、无付费 API。其输出只能用于独立验收，尚不作为普通用户正式综合结论。
