## 预留与结算

使用 Day8B 已下载的官方 tokenizer，直接本地加载并校验 SHA256，不执行远程示例代码、不改变 requirements。实际完整 prompt 内容 Token ×1.15＋256，向上取整到256；审核阶段使用真实草稿重新计量，没有“测量”占位。输入包装估计仍有误差，不能称为厂商准确账单。

发送前原子检查：

`已结算量 + 活跃/未知用量的预留 + 本次输入预留 + 固定最大输出 <= 250000`

费用预留：

`输入预留 × 高峰未命中费率 + 最大输出 × 高峰输出费率`

与已承诺费用合计不得超过US$0.15。采用整数 nano-USD，1美元=10^9 nano-USD，没有浮点金额误差。请求次数、批次数、问题集合也在同一锁内检查；没有先检查再并发花费的窗口。

实际 usage 必须包含 prompt/completion/total 和缓存命中/未命中数量，严格整数非负、相加一致、位于预留范围。只有这些条件满足才能按实际数量释放差额。仍按高峰收费推算，不将该推算称为实付账单。

失败、取消、超时均不恢复请求次数；usage 缺失或不一致时保留全额预留并停止全部后续请求。若有效 usage 超出预留，保留至少预留及报告量中的较大值，记录数量并停止，不能将超额报告当0。403/500/502不读取错误正文，不猜测免费。

## 持久化和防重置

独立 SQLite 仅保存白名单预算事件，不使用生产数据库。事件追加，UPDATE/DELETE被数据库触发器拒绝。外部 `.anchor` 保存事件数和内容摘要；`.registered` 作为一次登记标记。OS文件锁＋SQLite BEGIN IMMEDIATE覆盖检查和修改，提交并fsync后更新外部锚点。

固定真实运行目录预留为 `private/day8b1/records`，登记/锚点在不同目录 `private/day8b1-anchors`，均Git忽略、无网页访问接口。真实运输拒绝其他账本目录。Mock用独立文件名及mock-records目录，不影响将来的真实额度。

- 重新启动、刷新、重新构造执行器只会打开同一账本，不会初始化新预算。
- 删除账本、运行事件或锚点导致失败关闭。即使删账本及锚点，登记标记仍拒绝重新初始化。
- constructor、run_case、run_batch都不自动创建账本。
- 崩溃遗留活跃请求保留额度、占据槽位，不自动重试或清零。
- DB已提交但锚点未写完的崩溃同样停用；宁可人工审查恢复状态，不猜测旧额度。
- 第二批需要第一批报告摘要登记及新的显式服务器端授权；报告通过本身不构成批准。
- 价格日期过期先拒绝。之后可追加“官方价格未变”的复核记录，两个批次计数及费用完全保留；价格变化则拒绝，需要另行设计保留原花费的迁移，不能删除预算重开。

边界：这是服务器应用的防重置措施，不声称能对抗有权删除/回滚**账本、登记、锚点全部服务器状态**的Windows管理员。普通网页没有写入这些目录、删除预算或授权接口；未来部署应限制服务器目录权限。厂商账单也不是本工具可设置的账户硬限额，Token包装误差或厂商调价不能由本地撤销，异常时立即停止是最后保护。

## 授权与运输

本轮脚本只有 Mock 模式，没有live开关、真实授权CLI或公开解释路由。服务器私有 `authorize` 是记录已核对的人类授权的能力，本身不能证明人类已经批准；本轮没有对真实账本调用它，也没有读取真实凭据。

未来只有明确用户授权后才能登记第一批；第二批需要新的授权。每次运输绑定账本预留、固定case/phase、wire摘要，dispatch和worker均只能认领一次。子进程加载配置前复核固定真实账本、当前价格和认领状态，不能把普通字符串直接交给Provider。

复用原HTTPS运输：无环境代理、全部3xx禁止跟随、TLS正常校验、固定目标地址；非流式、temperature=0、thinking disabled。没有SDK/HTTP/JSON修复重试。

每次自有子进程20秒socket timeout、22秒监督期限、2秒清理；仅该进程kill/communicate回收后结算释放并发槽。清理失败保留活跃槽并停批。子进程另有22秒看门狗，避免父进程异常退出后持续执行。50秒每例/300秒批次是调用调度限制，不声称能约束操作系统卡死的硬实时行为。

## 数据最小化

账本不保存问题、prompt、正文、原始envelope、认证头或异常文本。只存固定案例ID、phase、指纹、预留、白名单usage、安全HTTP状态、耗时、错误码和授权参考摘要。

合成测试报告可保存通过现有检查及独立审核的测试渲染和必要证据ID。拒绝文本不保存、不显示；内部审核reason、完整原始请求/响应、Key、封印不进入报告。实际模型语义质量仍需另行真实验收和原始来源审查。
